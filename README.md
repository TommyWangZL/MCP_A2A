# Multi-Agent Customer Service System (A2A + MCP)

This repository contains a full multi-agent customer service system implemented with:

- A2A (Agent-to-Agent) protocol
- MCP (Model Context Protocol) over Streamable HTTP
- FastMCP server exposing real SQLite CRUD tools
- Google ADK 1.9.0 agents using Gemini 2.5 Pro
- A Router Agent orchestrating Customer Data + Support Agents
- A fully correct MCP initialize → tools/call pipeline

Everything runs locally using Python and Uvicorn.
